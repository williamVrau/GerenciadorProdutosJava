# 📦 Sistema Básico de Cadastro de Produtos

Este é um programa simples de console desenvolvido para praticar estruturas básicas de programação como `switch-case`, `for`, `for-each` e manipulação de listas usando `ArrayList`.

## 🛠️ Funcionalidades

- ✅ Cadastro de produtos (adiciona nomes de produtos a uma lista)
- 📋 Listagem de todos os produtos cadastrados
- ❌ Remoção de um produto da lista (com visualização prévia dos itens)
- ✏️ Alteração de um produto existente
- 🧠 Estruturas utilizadas:
    - `switch-case` para controle de menu
    - `for` e `for-each` para percorrer a lista
    - `ArrayList` para armazenar os produtos dinamicamente

## 📌 Como funciona

Ao executar o programa, um menu com as opções será exibido:


O usuário pode interagir digitando o número correspondente à ação desejada.

1. O usuário escolhe **Cadastrar Produto**, insere o nome, e o item é adicionado à lista.
2. Ao escolher **Listar Produtos**, o programa exibe todos os produtos utilizando `for` .
3. Em **Remover Produto**, a lista é mostrada com índices e o usuário escolhe qual deseja remover.
4. Para **Alterar Produto**, o usuário escolhe o índice do item a ser alterado e fornece o novo nome.
